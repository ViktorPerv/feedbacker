## ФАЗА 5R — Конструктор виджетов + видео-отзывы ✅ ВЫПОЛНЕНО

**Статус:** ✅ Завершена 12.11.2026 · 149 тестов (было 127)

### 5R.1 Конструктор виджетов — ✅

> В исходном плане: Фаза 5 (JS-виджет), но только masonry.
> Сейчас masonry реализован; остальные layout'ы — v2+.

**Задача:** дать пользователю создавать несколько виджетов на одно пространство с разными layout'ами.

| Layout | Описание | Статус |
|--------|----------|--------|
| `masonry` | Стена из отзывов (CSS-колонки) | ✅ |
| `carousel` | Горизонтальная прокрутка со стрелками | ✅ |
| `single` | Один отзыв для hero / лендинга | ✅ |
| `badge` | Аватарки + рейтинг + количество | ✅ |

**Артефакты:**

| Компонент | Файл |
|-----------|------|
| Миграция | `2026_11_12_170000_create_widgets_table.php` |
| Enum | `app/Enums/WidgetLayoutEnum.php` — `label()`, `description()`, `defaultConfig()`, `options()`, `supportsColumns()`, `supportsLimit()` |
| Модель | `app/Models/Widget.php` — route key = **token**, `configWithDefaults()`, `embedUrl()`, `embedSnippet()` |
| Политика | `app/Policies/WidgetPolicy.php` — делегирует в `SpacePolicy` |
| Валидация | `app/Http/Requests/WidgetRequest.php` — фиксированный набор ключей конфига |
| Контроллер | `app/Http/Controllers/WidgetController.php` — index/create/store/edit/update/destroy |
| Маршруты | `spaces/{space}/widgets`, `/create`, `/{widget}/edit` |
| Vue | `Pages/Spaces/Widgets/{Index,Create,Edit}.vue` + `Partials/{WidgetForm,WidgetPreview}.vue` |
| Go | `Widget(ctx, token)`, `OptionsFromConfig()`, `/w/{slug}/{token}.js`, `/api/public/widgets/{token}` |
| Тесты | `tests/Feature/WidgetTest.php` — 22 теста; Go: handler + widget пакеты |

**Ключевые решения:**
- Токен — 24 символа, **не UUID**: попадает в исходники сторонних сайтов
- Токен **стабилен при редактировании** — иначе сломаются все встраивания
- Slug в `/w/{slug}/{token}.js` декоративен, но обязан совпадать с токеном (иначе 404, а не чужие отзывы)
- Layout-правила важнее сохранённого конфига: `single` всегда = limit 1 + `featured_only`
- Фильтры `featured_only` и `min_rating` — на каждый виджет
- Кеш Go ключуется по slug **+ фильтрам**
- Конфиг — фиксированный набор ключей, а не свободный blob: рендерер может полагаться на форму

## ФАЗА 6R — Email-уведомления + теги + полнотекстовый поиск

**Оценка:** 16-24 часов

> В исходном плане: часть Фазы 4 (теги, поиск, email).
> Эти фичи были запланированы в MVP, но отложены ради более критичного функционала.

### 6R.1 Email-уведомления

**Задача:** отправлять email владельцу пространства при новом отзыве.

1. Настроить `MAIL_*` в `.env-common` (SMTP или log для локальной разработки)
2. Создать `NewTestimonialNotification` (Laravel Notification + mail канал)
3. Отправлять при создании отзыва через `CollectionPageController@store`
4. Проверить, что отправка не блокирует HTTP-ответ (queue)

### 6R.2 Теги

> Поле `tags` (json) в таблице уже есть. Нет UI и фильтрации.

1. Поле ввода тегов в inbox (чипсы: добавить/удалить)
2. API: `PATCH /testimonials/{id}/tags` (sync массив)
3. Фильтр по тегам в inbox (multiselect)
4. Отображение тегов на карточках в inbox

### 6R.3 Полнотекстовый поиск (PostgreSQL `tsvector`)

> Сейчас поиск: `LIKE %term%` — работает, но без ранжирования и morphology.

1. Миграция: generated column `search_vector tsvector` на `testimonials`
2. GIN-индекс
3. Замена `LIKE` на `to_tsquery` + `ts_rank` в `TestimonialController@index`
4. Поддержка русского языка в конфигурации `tsvector`

### 6R.4 Рефакторинг публичной отправки в Go (опционально)

> В исходном плане: публичная отправка отзыва через Go (rate limiting, высокая скорость).
> Сейчас отправка через Laravel с `throttle:10,1` — работает, но нарушает исходную архитектуру.

1. `POST /api/public/spaces/{slug}/testimonials` в Go
2. Перенос валидации (можно оставить StorePublicTestimonialRequest и вызывать из Go)
3. Убрать `throttle` из Laravel — он переедет в Go `RateLimiter`

> **Приоритет:** низкий. Текущая схема работает, задержка не критична для MVP.
> Делать только если нужна производительность на 1000+ RPM.

## ФАЗА 7R — Хранилище файлов (MinIO / S3) ✅ ВЫПОЛНЕНО

**Статус:** ✅ Завершена 12.11.2026 · 171 тест (было 149)

> В исходном плане: часть Фазы 1. Была заблокирована недоступностью образа MinIO.

### 7R.1 MinIO в Docker Compose — ✅

**Как обошли блокировку:** upstream-образ `minio/minio` отозван из Docker Hub,
а каталог Bitnami переехал. Рабочий образ — **`bitnamilegacy/minio:latest`**
(MinIO 2025.5.24, `mc` в комплекте).

| Компонент | Реализация |
|-----------|-----------|
| Сервис | `minio` — порты 9000 (API) / 9001 (консоль), `user: root` чтобы entrypoint сделал chown тома |
| Автосоздание бакета | `MINIO_DEFAULT_BUCKETS=feedbacker` |
| Публичный доступ | one-shot сервис `minio-init` → `mc anonymous set download` |
| Healthcheck | `curl -f http://localhost:9000/minio/health/live` |
| Том | `minio_data` |

**Ключевое решение — анонимный download, а не presigned URL.** Логотипы и
аватарки показываются на публичных страницах и в виджетах, то есть являются
публичными активами; подписанные ссылки истекали бы и ломали встроенные стены.

### 7R.2 Загрузка файлов — ✅

| Маршрут | Поле | Кто |
|---------|------|-----|
| `POST /spaces/{slug}/logo` | `logo` | владелец или `spaces.update.any` |
| `DELETE /spaces/{slug}/logo` | — | то же |
| `POST /testimonials/{id}/avatar` | `avatar` | владелец или `testimonials.moderate.any` |
| `DELETE /testimonials/{id}/avatar` | — | то же |

**Артефакты:**
- `app/Support/Uploads.php` — `replace()`, `forget()`, `url()`; **ни один вызывающий не называет диск**
- `app/Http/Requests/UploadImageRequest.php` — PNG/JPG/WebP, ≤2 МБ, ≤2400×2400
- `SpaceLogoController`, `TestimonialAvatarController`
- Vue: загрузка логотипа в брендинге с превью и удалением

**Решения:**
- **SVG отклоняется** — может нести скрипт, а бакет открывается браузером напрямую
- **Правило `dimensions` не косметика** — decompression bomb проходит проверку размера, но не эту; для чтения размеров GD должен быть собран с `--with-webp`
- **Пути детерминированы** (`spaces/{id}/logo.{ext}`), поэтому замена логотипа удаляет старый файл с любым расширением
- **`AWS_ENDPOINT` — маршрут контейнера, `AWS_URL` — маршрут браузера**; перепутать = ссылки, которые загружаются, но дают 404

### 7R.3 Временные ссылки — ❌ не требуется

Presigned URL противоречат модели публичных активов (см. выше). CDN —
задача эксплуатации, не кода: достаточно поменять `AWS_URL`.

### Побочный результат: исправлен баг прав (из Фазы 2)

`php-fpm` всё это время работал под `www-data` (uid 82), а не под хостовым uid
1000 — поэтому `storage` приходилось держать в 777, а `make fix-perms` ломал
запись PHP (это и была причина 500 в Фазе 2).

**Причина:** охранная проверка `id -u ${UID}` — busybox `id` **не резолвит
числовой uid**, поэтому проверка падала даже при существующем пользователе, и
ветка `else` оставляла пул на `www-data`.

**Исправление:** проверка по имени (`id -u app`), build-args переименованы в
`APP_UID`/`APP_GID` (во избежание коллизии с shell-спецпеременными).
Теперь `storage` работает на 775 без world-write.

> **Известный пробел:** удаление пространства удаляет строку, но оставляет
> объекты в бакете. Удалять файлы внутри транзакции хуже, чем оставить сироту —
> нужен фоновый sweep-джоб.

## РАСХОЖДЕНИЯ С ИСХОДНЫМ ПЛАНОМ

| Исходный план | Что изменилось | Причина |
|---------------|----------------|---------|
| `users.id` UUID | bigint auto-increment | Breeze не дружит с UUID без доп. пакетов |
| Vue 3 + Blade | Inertia.js (SPA) | Breeze 2.x по умолчанию |
| PHP 8.3 | PHP 8.4 | Требование composer |
| Go 1.22 | Go 1.23+ | Требование pgx/v5 |
| Laravel 11 | Laravel 13 | Последняя стабильная на момент старта |
| Laravel Queues для уведомлений | Не сделано | Отложено в Фазу 6R |
| MinIO | Не сделано | Блокировка Docker Hub |
| Отправка отзыва через Go | Сделано через Laravel | Упрощение; throttle:10,1 |
| Redis для кеша виджетов | In-process TTL cache (Go) | Быстрее для одного инстанса; `cache.Cache` — seam |
| Token bucket в Go middleware | Fixed-window counter | Проще, предсказуемее для 60 req/min |
| PostgreSQL `tsvector` | `LIKE %term%` | Быстрее реализовать; апгрейд в Фазе 6R |
| PostgreSQL `TEXT[]` для тегов | `json` | Совместимость с SQLite (до переезда на Postgres) |
